# MedBridge Global design system — landing page direction

## Design intent

An international healthcare coordination service that feels medically trustworthy and personally considerate. The experience should read as a care navigator, not a consumer wellness app: calm clarity, credible detail, and supportive human guidance.

## Typography (locked)

- **Outfit** — all UI, headings, labels, body copy, and buttons.
- **Reenie Beanie** — only the single handwritten emphasis treatment already used in the hero.
- Do not replace, add, or alter font families.

## Palette (current approved direction)

| Token | Value | Intended use |
| --- | --- | --- |
| Deep navy | `#0B2545` | Navbar, headings, primary text, dark CTA surfaces |
| Medical teal | `#0F9D8A` | Primary brand accent, actions, active and success states |
| Soft mint | `#DDF4EF` | Healthcare cards, callouts, and supportive highlights |
| Ice blue | `#EAF4FA` | Secondary sections and calm informational surfaces |
| Pure white | `#FFFFFF` | Main canvas and elevated surfaces |
| Slate | `#526777` | Body copy and secondary labels |
| Soft gray | `#F5F8FA` | Alternate sections, dividers, and quiet borders |

Use medical teal deliberately rather than on every interactive element. Deep navy carries authority and contrast; mint and ice blue should remain low-intensity background fields. Do not reintroduce coral, lavender, warm stone, or unrelated accent colors.

## Layout

- Main landing content: max 1152–1240px with responsive 24px mobile / 48px tablet / 64px desktop gutters.
- Hero: use clear 12-column desktop structure, stacking to one column on mobile.
- Section rhythm: 96–140px desktop, 64–88px mobile.
- Surfaces: white and warm off-white; no heavy glass, excessive blur, or generic card grids.

## Interaction

- 150–250ms ease-out state changes.
- Primary buttons: 1–2px visual lift only; no bouncy scale.
- Support `prefers-reduced-motion` for all introductory animations.

## Medical trust motifs

- Subtle line icons, document edges, care-path connectors, factual microcopy, and accreditation-style proof.
- Avoid stock medical imagery, cartoon illustrations, gradients that obscure information, or wellness-brand visual clichés.
